- Minimum supported Android versions/devices justified by feature needs
- Offline/data model and preservation requirements, if any

## Engineering startup after approval
1. Choose the simplest stack that satisfies the brief; avoid copying Lab 1 Canvas or Lab 2 Compose automatically.
2. Create independently installable app shell with stable identity; isolate feature logic and state from host/navigation.
3. Add build/test CI, a factual evidence ledger and data-migration tests only if persisted data exists.
4. Use Creative/Feature/Safety/Release gates by actual risk; preserve maximalist motion and older-device compatibility.
5. Prototype and measure on real devices before claiming performance; no speculative universal library.

This is a deliberate no-invention checkpoint, **not** a prohibition on future creative development.
